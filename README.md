# runtime-components

Personal runtime configuration files for bash, zsh, vim, gdb, and git.

These files make a new computer or server feel the same as my usual setup.

## Files

- `.bashrc` — settings loaded by bash
- `.zshrc` — settings loaded by zsh
- `.vimrc` — settings loaded by vim
- `.gdbinit` — settings loaded by gdb
- `.gitconfig` — git aliases and defaults
- `install.sh` — copies the files into the home directory

## Install

```bash
./install.sh
```

Preview without changing anything:

```bash
./install.sh --dry-run
```
